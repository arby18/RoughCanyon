# RoughCanyon

Transforms raw sensor data from IoT devices into actionable insights for maintenance and operations teams.

With RoughCanyon, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughCanyon.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure RoughCanyon, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
